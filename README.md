A single-player 2D canvas arena survival in a deep-sea bioluminescent abyss: you are a bloom wisp, swimming with WASD or the arrow keys, auto-firing pulses, dashing with Space, gathering glow-gems from fallen enemies, and choosing one of three upgrades on every level. Waves grow harder, a boss Angler surfaces every five waves, and killing the wave-10 Angler wins the run (Endless continues after). No build step, no network requests, all art procedural, sound synthesized with WebAudio.

## Play it

```sh
node serve.ts        # serves game/ on http://localhost:8080
```

Open the page and press Space or click to dive.

| Key | Action |
| --- | --- |
| W A S D / arrows | Swim |
| Space | Dash (also confirms) |
| 1–3 / click | Choose a level-up upgrade |
| P / Esc | Pause |
| M | Mute |
